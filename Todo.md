# 📋 Дорожная карта и ТЗ проекта izinet

> **VPN Subscription Management Platform** — сервис управления VPN-подписками с личным кабинетом пользователя, биллингом Enot.io, автоматической выдачей мультпротокольных конфигураций (VLESS-Reality, Hysteria 2, AmneziaWG) и синхронизацией узлов 3x-ui.

---

## 1. Общие сведения и архитектурный стек

### 1.1 Назначение системы
Веб-сервис для управления VPN-подписками с личным кабинетом пользователя, системой оплаты через Enot.io (СБП, карты, крипто), мультиклиентской поддержкой протоколов обхода блокировок и синхронной выдачей ключей/конфигураций сразу на все активные VPN-ноды.

### 1.2 Сетевая архитектура и маршрутизация портов
```
Входящий трафик (Интернет)
  │
  ├─► Порт 443 (TCP) ──► Xray / 3x-ui (VLESS-Reality)
  │                        ├── VPN клиенты ──► Проксирование в Интернет
  │                        └── Браузеры (non-Reality) ──► Fallback: host.docker.internal:3443
  │                                                            │
  │                                                            ▼
  │                                                     Nginx (Порт 3443)
  │                                                            │ (proxy_pass)
  │                                                            ▼
  │                                                     Docker: izinet-app (Порт 3005)
  │
  ├─► Порт 443 (UDP) ──► Hysteria 2 (Standalone daemon / systemd)
  │
  ├─► Порт 51820 (UDP) ──► AmneziaWG (awg0 / Host kernel)
  │
  └─► Порт 2053 (TCP) ──► 3x-ui Admin Panel (Docker x3-ui)
```

- **Критическое правило портов**: Порт 3005 используется в Docker/Production; порт 3000 — среда разработки AI Studio. Запрещен жесткий хардкод `PORT=3000`.

### 1.3 Технологический стек
| Слой | Стек технологий |
| :--- | :--- |
| **Frontend** | React 18, TypeScript, Tailwind CSS, Lucide Icons, Vite |
| **Backend** | Node.js (Express monolith), Supabase (PostgreSQL, Auth, RLS) |
| **VPN Core** | 3x-ui (Xray Reality TCP 443), Hysteria 2 (UDP 443), AmneziaWG (awg0 UDP 51820) |
| **Платежи** | Enot.io API (HMAC SHA-256 подписи, СБП, карты) |
| **Деплой** | Выделенный VPS (Ubuntu), Docker Compose, Nginx Reverse Proxy, Certbot SSL |
| **Методология** | Ponytail (`/skills/ponytail/` — минимализм, smallest complete change) |
