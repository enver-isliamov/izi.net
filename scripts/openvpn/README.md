# OpenVPN на izinet: установка и выдача файлов пользователям

Три скрипта, которые разворачивают OpenVPN на VPS и выдают пользователям готовые `.ovpn`:

| Файл | Что делает |
|---|---|
| `setup_openvpn.sh` | Ставит openvpn + easy-rsa, создаёт PKI (CA, сертификат сервера), поднимает сервер на UDP 1194, включает ip_forward + NAT, открывает порт в UFW, запускает systemd-службу |
| `new_client.sh <имя>` | Выдаёт клиенту файл `/root/ovpn-clients/<имя>.ovpn` со вшитыми сертификатами и общим tls-crypt ключом |
| `revoke_client.sh <имя>` | Отзывает доступ (сертификат попадает в CRL, служба перезапускается) |

## Порядок

```bash
cd /opt/izinet && git fetch && git reset --hard origin/main
bash scripts/openvpn/setup_openvpn.sh          # один раз
bash scripts/openvpn/new_client.sh test-user   # проверочный клиент
# забрать файл: /root/ovpn-clients/test-user.ovpn
```

Порт по умолчанию — UDP 1194 (свободен: 443 занят Reality-инбаундом, 3443 — nginx). Можно изменить:
`OVPN_PORT=1195 bash scripts/openvpn/setup_openvpn.sh`.

## Проверка

```bash
systemctl is-active openvpn-server@server      # active
ss -lunp | grep 1194                            # слушает UDP 1194
journalctl -u openvpn-server@server -n 50       # логи подключений
cat /etc/openvpn/openvpn-status.log             # кто сейчас подключён
```

## Важные ограничения (честно)

1. **DPI в РФ.** У OpenVPN узнаваемый handshake — его часто блокируют/замедляют. Для обхода подходит хуже, чем VLESS Reality и Hysteria2. Держать его стоит как вариант совместимости (роутеры, старые устройства), а не как основной протокол.
2. **TCP-режим не поможет обойти 443** — этот порт уже занят Reality-инбаундом; TCP-вариант можно повесить на отдельный порт (например 1194/tcp), но устойчивость от этого не вырастет.
3. **IPv6** в конфиге не раздаётся: только IPv4 (10.8.0.0/24), чтобы не было утечек.
4. **DNS** внутри туннеля принудительно 1.1.1.1 / 8.8.8.8 (не РФ-резолверы).
5. Доступ выдаётся **файлом** — он не привязан к лимитам подписки в нашей базе. Если нужно учитывать трафик/срок, это отдельная интеграция (в админке пока не сделана).
