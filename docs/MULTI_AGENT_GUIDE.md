# 🤖 РУКОВОДСТВО ПО МУЛЬТИ-АГЕНТНОЙ РАЗРАБОТКЕ IZINET (MULTI-AGENT SYNC)

> Этот документ определяет правила взаимодействия всех AI-агентов (Google AI Studio, Claude Code, Cursor, Windsurf, Aider, Copilot, CLI-агенты) и разработчиков.

---

## 🎯 1. ПРИНЦИП ЕДИНОГО ИСТОЧНИКА ПРАВДЫ (SINGLE SOURCE OF TRUTH)

- **`AGENTS.md`** — главный закон проекта. Любой агент обязан руководствоваться правилами из `AGENTS.md`.
- **`fix.md`** — журнал аудита. Каждый исправленный баг обязан быть зафиксирован. Запрещено удалять прошлые записи!
- **`Todo.md`** — единая очередь задач. Запрещено удалять выполненные задачи, только помечать `[x]`.
- **`docs/ARCHITECTURE.md`** — нерушимая схема сети (Xray Reality 443 ⇄ Nginx 3443 ⇄ Hysteria2 UDP ⇄ Node.js 3000).

---

## 🛡️ 2. ШЕСТЬ ЗАПОВЕДЕЙ ЛЮБОГО AI-АГЕНТА В ПРОЕКТЕ

1. **Никогда не ломать VLESS и Hysteria2:**
   - Прежде чем трогать логику генерации ссылок, инбаундов или работы с 3x-ui API, прочтите `docs/ARCHITECTURE.md` и `docs/vless-checklist.md`.
2. **Read Before Edit (Чтение перед правкой):**
   - Перед редактированием файла обязательно изучите его контекст (`grep` по проекту на использование функций).
3. **Маркировка правок тегами FIX-ID:**
   - Если вносится нетривиальное исправление, в коде оставляется комментарий:  
     `// FIX-ID: [ID] Краткое пояснение причины решения`.
   - Другие агенты **СТРОГО НЕ ИМЕЮТ ПРАВА** удалять эти блоки без согласования.
4. **Изоляция изменений:**
   - Не делайте глобальных рефакторингов "ради красоты". Меняйте только то, что относится к текущей задаче.
5. **Безопасность секретов:**
   - Никаких API-ключей, токенов ботов или паролей в коде и репозитории. Только переменные окружения и Supabase.
6. **Обязательная проверка перед сдачей:**
   - Перед завершением ответа выполните `npm run lint` и `npm run build`.

## 🔄 3. ПРОЦЕСС ВЫПОЛНЕНИЯ ЗАДАЧИ (WORKFLOW)

```text
[1. Чтение контекста] ──> [2. Проверка связей] ──> [3. Точечное изменение] ──> [4. Проверка сборки] ──> [5. Логирование]
  (AGENTS.md + fix.md)       (grep по вызовам)         (с комментарием FIX-ID)       (lint + build)        (fix.md + Todo.md)
```
