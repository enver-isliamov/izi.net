# ISSUE-002: VPN и сайт недоступны из России (Крым, МТС)

**Статус:** Решено, готово к проверке пользователем
**Дата:** 2026-11-14
**Серьёзность:** Критическая

## Описание
Пользователь в Крыму (МТС/Infostroy LLC, ASN 208397) сталкивался с:
1. Ошибкой обновления профиля подписки в Hiddify
2. Сбросом/таймаутом при прямом подключении по протоколу Reality на 443 порт

## Первопричины
1. **Сайт и API подписки:** В DNS `izinet.online` был в режиме DNS-only (серое облако), что приводило к сбросу пакетов ТСПУ на зарубежный IP `89.125.17.44` с именем `izinet.online`.
2. **Блокировка прямого порта 443 на IP хостинга:** На некоторых провайдерах (Aeza, МТС Крым) ТСПУ сбрасывает TCP/TLS-сессии на порт 443 к пулу HOSTKEY. При этом порты 2022 (gRPC) и 2088 (XHTTP) свободны и отвечают за 35-50 мс.
3. **Белые списки ТСПУ:** Отечественные сервисы (в т.ч. `docs.yandex.ru`, `disk.yandex.ru`) находятся в приоритетных белых списках ТСПУ.

## Реализованные решения (/ponytail)
1. **Cloudflare Proxy (Оранжевое облако):** 
   - Запись `izinet.online` переведена в `Proxied` (`cf_tags=cf-proxied:true`).
   - Проверено с узлов `ru1` и `ru2` (`check-host.net`): HTTP 200 за 250-300 мс со всех сетей РФ без VPN.
2. **Cloudflare Auto WebSocket узел (`izinet_Cloudflare_Auto`):**
   - Узел VLESS+WS через защищенный Anycast IP Cloudflare `izinet.online:443`.
   - Проверено сквозным curl-тестом через Xray: `HTTP/2 200`.
3. **Reality маскировка под Яндекс Документы (`docs.yandex.ru`):**
   - В 3x-ui добавлены `docs.yandex.ru`, `disk.yandex.ru`, `telemost.yandex.ru` в Reality `serverNames`.
   - В `config.ts` сформированы узлы `izinet_OneD_Reality_Yandex`, `izinet_OneD_gRPC_Yandex` и их прямые IP-варианты.
   - Проверено на порту 443 и 2022: handshake проходит успешно, отдает HTTP 200.
4. **Нестандартные порты против блокировок 443:**
   - Добавлены прямые узлы `gRPC` (порт 2022) и `XHTTP` (порт 2088).
